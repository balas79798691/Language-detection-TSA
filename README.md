# Language-detection-TSA
🌍 Language Detection using Python

📌 Project Overview

This project detects the language of a given sentence or text using Natural Language Processing (NLP).

The project uses the Python "langdetect" library to identify the language and display its language code and detection probabilities.

🎯 Objective

The main objective of this project is to automatically identify the language of user-provided text.

🛠️ Technologies Used

- Python
- Google Colab
- Natural Language Processing (NLP)
- LangDetect

⚙️ How It Works

1. The user enters a sentence or text.
2. The program processes the input using the "langdetect" library.
3. The language is detected automatically.
4. The program displays:
   - Detected language
   - Language code
   - Detection probabilities

📚 Supported Languages

The project can detect many languages, including:

- Telugu

- Kannada

- Spanish

🚀 How to Run

Using Google Colab

1. Open Google Colab.
2. Upload "Language_Detection.ipynb".
3. Run the installation cell.
4. Run the language detection cell.
5. Enter a sentence when prompted.
6. View the detected language and probability.

Input

Hello, how are you today?
